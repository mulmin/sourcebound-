# sourcebound

**검증된 출처에만 묶인(source-bound) 지식 AI.** 공공기관 자료를 근거로만 답하고,
문장마다 출처와 근거 일치도를 표시하며, **근거가 없으면 답하지 않는다.**

첫 적용 도메인은 **육아**다. 부모들이 육아 고민을 범용 챗봇에 묻지만, 그럴듯하게 틀린 답(환각)은
영유아 건강처럼 위험이 큰 영역에서 실제 해가 될 수 있다. 이 프로젝트의 철학은
"AI를 믿어라"가 아니라 **"사용자에게 검증 수단을 준다"** 이다.

| | |
|---|---|
| 지식팩 | 공공기관 실제 출처 **150문서 / 4,120청크** |
| 검색 | Recall@5 **0.96** · MRR **0.74** |
| 거부 | 재현율 **0.83** · 오거부 **0.00** |
| 인용 | 평균 근거 일치도 **0.91** · 모순 0 · 미인용 0 |

## 무엇이 다른가

1. **문장 단위 출처 표기** — 답변의 각 문장에 인용 `[n]`과 근거 일치도(%)를 붙인다.
2. **근거 없으면 거부** — "비트코인 사도 될까요?" 같은 도메인 밖 질문에 답하지 않는다.
3. **원문 즉시 확인** — 인용을 누르면 원문의 해당 구절이 하이라이트된다.
4. **라이선스 인지형 처리** — 변경금지 자료는 요약하지 않고 원문 그대로 인용하며,
   출처를 켜고 끌 수 있고(구독 모델), 출처별 인용 기여도를 집계한다(수익분배 지표).

## 빠른 시작

```bash
pip install -r requirements.txt
python -m backend.ingest          # 지식팩 → 인덱스 (저장소에 인덱스 포함, 생략 가능)
uvicorn backend.main:app          # http://localhost:8000
```

`.env` 파일에 키를 넣으면 기능이 켜진다(없어도 **추출 모드로 끝까지 동작**한다):

```
OPENAI_API_KEY=sk-...          # 자연스러운 답변 생성 (없으면 추출 모드)
DATA_GO_KR_KEY=...             # 질병관리청 국가건강정보포털 API 수집용
```

## 파이프라인

```
질문 → ① 하이브리드 검색 → ② 리랭킹·거부 → ③ 인용 생성 → ④ 3층 검증 → ⑤ 원문 연결
```

| 단계 | 모듈 | 하는 일 |
|---|---|---|
| ① 검색 | `retriever.py`, `lexical.py` | e5 임베딩(의역에 강함) + BM25/kiwi(수치·약물명에 강함) → RRF 융합 |
| ② 리랭킹·거부 | `reranker.py` | 교차 인코더가 "질문에 답이 되는가"로 재채점. 이 점수로 **답변 거부**를 판정 |
| ③ 생성 | `generator.py` | 인용 강제 프롬프트(JSON 구조화). OpenAI→Anthropic 자동 선택, 키 없으면 추출 모드 |
| ④ 검증 | `verifier.py`, `entailment.py` | 코사인 유사도 + **부정어 극성** + NLI로 인용 타당성 점검, 출처 간 상충 탐지 |
| ⑤ 원문 | `main.py` | 청크의 원문 오프셋으로 해당 구절 하이라이트 |

**왜 3층 검증인가**: 코사인 유사도는 "비슷한가"를 잴 뿐 "근거가 문장을 함의하는가"가 아니다.
"먹여도 된다"와 "먹이면 안 된다"는 단어가 겹쳐 유사도가 높다. 그래서 부정어 극성을 함께 보고,
그래도 남는 불확실성은 **경고 + 원문 열람**으로 사용자 검증에 위임한다.

## 지식팩

| 출처 | 건수 | 수집 방법 |
|---|---|---|
| 질병관리청 국가건강정보포털 | 112 | 공공데이터포털 오픈API (`backend/kdca_collect.py`) |
| 공식 발간물 PDF | 15 | 복지부 초보아빠 육아가이드, 질병관리청 2026 예방접종 가이드, 건강증진개발원 이유식·모유수유 등 |
| 웹 수집 | 23 | 정책브리핑·아이사랑·소아과학회 등 |

문서마다 `title / publisher / url / license` 메타데이터를 보존한다.
원본 PDF(343MB)는 저장소에 포함하지 않는다 — 텍스트는 인덱스에 들어 있고 공공기관에서 재다운로드 가능하다.

**문서 추가**: `data/knowledge_pack/`에 `.md`(아래 형식) 또는 `.pdf`/`.hwpx`(+ `파일명.pdf.meta`)를 넣고 `python -m backend.ingest`

```
title: 문서 제목
publisher: 발행 기관
url: https://원문-링크
license: 공공누리 제1유형
---
본문…
```

## 평가

```bash
python -m eval.run_eval          # Recall@k · MRR · 거부 재현율 · 오거부율 · 인용 충실도
```

평가셋은 `eval/questions.jsonl`(양성 23 / 음성 6, 복수 정답 라벨).
음성에는 **적대적 문항**("강아지 예방접종은?", "성인 고혈압 약은?")을 넣어 도메인 경계를 시험한다.

## 설정

| 환경변수 | 기본 | 설명 |
|---|---|---|
| `OPENAI_MODEL` | `gpt-5.4-mini` | 실측 비교로 선정(속도·정보 밀도 균형). 품질 우선이면 상위 모델로 교체 |
| `MPA_CANDIDATE_POOL` | `6` | 리랭킹 후보 수. **응답 시간을 좌우**(20이면 ~32초, 6이면 ~9초) |
| `MPA_DISABLE_RERANKER` | — | `1`이면 리랭커 해제(빠르지만 **거부 정확도가 무너지므로 비권장**) |

## 알려진 한계

- **응답 시간 ~14초**. 리랭커(교차 인코더)가 CPU에서 대부분을 차지한다. 더 작은 리랭커는
  도메인 밖 질문을 걸러내지 못해(변별력 역전) 채택하지 않았다 — 정확한 거부가 더 중요하다고 판단했다.
- **도메인 경계**. 검증된 의학 자료를 넓게 수집하면 성인 의학 내용이 섞여 들어와 경계가 흐려진다.
  현재는 소아 관련도 필터(고유 마커 2종 이상 + 밀도)로 조절한다.
- **환각률 RAG on/off 비교** 미측정 — 순수 LLM 베이스라인 실행이 필요하다.
- 인용 정확도의 엄밀한 판정은 사람/NLI 검수가 필요하다. 현재 지표는 자동 근사값이다.

## 로드맵

- **1단계(현재)**: 출처 기반 RAG 챗봇 + 문장 단위 검증 + 원문 뷰어
- **2단계**: 지식팩 마켓플레이스 — 전문가·출판사 등록, 구독, 인용 기여도 기반 수익 분배
- **3단계**: 의료·법률·교육 등 신뢰가 중요한 도메인으로 확장
