1. 시스템 개요

사용자가 육아 질문을 하면, 검증된 공공 육아 지식(지식팩)에서 근거를 검색해 그 근거에만 종속된 답변을 생성하고, 문장마다 출처와 답변–근거 유사도를 표기한다. 근거가 없으면 답변을 거부하고, 인용을 누르면 원문 구절을 하이라이트한다. 핵심 철학은 "AI를 믿어라"가 아니라 사용자에게 검증 수단을 준다이다.

5. 이번 개발에서 개선한 점

환경 회귀 복구

numpy 2.x가 torch 2.2를 깨뜨려 sbert·리랭커·NLI가 조용히 TF-IDF로 폴백돼 있던 문제를 발견·복구(numpy<2 고정). 검색 유사도 5~15% → 84~90% 정상화.

추출 답변 일관성

추출 모드가 여러 문서를 뒤섞어 상반된 내용을 잇던 문제를 상위 문서 한정·헤더 제거·중복 제거로 해결.

실데이터 지식팩 1차

개발용 샘플 5건을 제거하고 공공기관 실제 출처 23건으로 교체(출처 URL·라이선스 명기).

실데이터 지식팩 2차 — 공식 발간물 PDF 15종

복지부 초보아빠 육아가이드(제2유형), 질병관리청 2026 예방접종 가이드·백신별 VIS, 건강증진개발원 이유식·모유수유 3권, 건강검진 보호자 설명서 등 대형 발간물을 수집(POST·세션 게시판 다운로드 자동화 포함) → 총 38문서·1,842청크.

수집 파이프라인 확장

ingest에 PDF(PyMuPDF)·HWPX·HWP 파서 + 사이드카 메타데이터 추가.

라이선스 인지형 동작

출처 On/Off(구독 해지 시 즉시 검색 제외), 변경금지·판권 소스는 원문 그대로만 인용, 답변에 라이선스 배지, 출처별 인용 기여도 집계(수익분배 지표) — ebook 제휴의 기술적 초석.

지식 그래프 시각화

문서·청크·의미연결·출처충돌을 보여주는 /graph 페이지 신설. 대형 코퍼스에서는 문서 단위 그래프로 자동 전환.

국가건강정보포털 오픈API 연동

질병관리청 API(healthInfoList/healthInfo)를 해독(TOKEN 인증·구형 TLS 우회)하고, 서버 검색이 없어 내용 기반 소아 필터로 검증된 건강정보 300건을 자동 수집(backend/kdca_api.py·kdca_collect.py). 개정 시 재실행만으로 갱신.

스트레스 테스트 기반 재튜닝

코퍼스를 5건→12,137청크로 3,000배 확장하며 드러난 거부 누수·평가 라벨 한계를 반복 진단 — 복수 정답 라벨 도입, 거부 임계 재조정, 대형 코퍼스용 문서 단위 그래프 자동 전환. 12,137청크에서도 전 지표 목표 유지.

6. 남은 과제

  • 실제 자연스러운 답변(LLM 모드): 코드 준비 완료, ANTHROPIC_API_KEY 설정 시 활성화. 인용도는 검증 신호로 재정의.
